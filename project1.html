Ubuntu to USB Tutorial

Install Ubuntu on your thumb drive so you can have Linux in your pocket!



By 5h6nn0n (Shannon Alexis) • March 21, 2025 • est 30 min project

Contents:

Introduction Configuration Installation Authunication Launch Setup Conclusion

To complete this project you will need:

  • USB 3.0 Stick Type-A (preferably 64GB & up)
  • A funtional computer
  • Stable internet connection

** This tutorial assumes you are starting on Windows



START HERE

Download Rufus for Windows x64 Download Ubuntu for desktop
Here Here

Plug in your thumb drive and drag UBUNTU to it



Rufus configuration

Set ENIF

Set GPT

Set persistence amount (can be updated later)

- I chose to split my drive storage 50/50. In my 256GB drive, the persistence is set to 128GB, which means I have 128GB remaining for regular thumb drive storage too. Persistence is required to save and store data like on a regular computer. Otherwise, everything you've accomplished on the drive will be wiped each time you eject it.



The Installation Process

Logged into wifi

Select encryption LVM & LUKS

Select both proprietary software

Where: sda SANDISK

(or whichever brand of USB you used)



Authunication

Create pass phrase (encryption)

- Write this down (if set) and keep it stored in a secure location.

Create Password

- Set not required to log in (unless you want an additional layer of security).

- This password will be used for app store downloads.

Create Username



Windows Launch Setup

Restart PC and click F2 key on boot

Change USB to first in boot order

>>> sda -- USB

>>> sda2 -- Windows

>>> sda3 -- Boot

>>> sda4 -- Html

Set enif ask admin password

(choose Never unless you want an additional layer of security)

Secure boot mode from deploy to audit

Exit and will start up automatically



Conclusion

For this project, I wrote down the steps I took so that it would be easier to replicate the process in case I ever forgot without intending to release the recipe. Now you can safely open Ubuntu from any device that takes USB 3.0 type-A drives! I recommend to set the passwords, regular and admin, as required if you plan on plugging this into a device that is not exclusivly yours. Once inside, your computer data should be secured by BitLocker and will need the key to access your pictures, documents, etc that it normally does. I view mine as independant of the computer its connected to.
