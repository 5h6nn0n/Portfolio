Introduction

ZEPP OS is Amazefit's operating system for its smartwatch devices. As opposed to Apple or Android, ZEPP has a niche userbase with fewer apps in store to compete with, making it an attractive entry point for developers. It is also a completely free process from start to finish. I will walk you through the steps on how to build and publish your first app for ZEPP!



To complete this project you will juggle 4 screen views:

  • ZEPP OS Simulator
  • Watch Emmulator
  • VS code (or any editor)
  • Windows PowerShell


Walkthrough

Download ZEPP OS Simulator Download Node.js
reccommend: simulator_2.1.1_window_x64 if you don't already have it installed
Here Here

*** The package version of Node takes up more storage and includes MS VS Installer, VS Build Tools, Python Launcher, Python 3.14, and Node.js



1....Log in or create a developer account with zepp on web

2....Launch the zepp os simulator app and log in

3....Click the emulator icon (top left corner) and keep it open

4....Open Windows PowerShell


npm i @zeppos/zeus-cli -g

installs zeus command line package globally

zeus -v

shows the version number to make sure everything was installed correctly

cd project-folder

or whichever folder you want to store your project and work from

zeus create app-name

this is the easiest way to start the app. replace app-name with your intended app name, which can be changed later, then answer a series of questions (up and down keys to navigate between options, press space bar to select and enter key to accept)

cd app-name

go to app you just created

npm install

creates dependency packages

zeus login

will prompt you to login to your zepp account. if successful, you will redirected to a localhost url. you only need to do this once as the credentials will be saved even when you exit out of powershell.

zeus status

shows you whether you are logged in and connected

zeus dev

push to zepp os simulator

Edit your app !!

open the index.page.js file in /pages and edit with your code. don't forget to any new user-facing pages & sub-folders next to this path into the app.json file in root folder, which acts as the directory for indexing!

SHIFT + C then CTRL + C

cancels dev from listening for changes so you can input another command

zeus build

creates the .zab file inside /dist/ folder, which is a compressed version of your app and will be the file you submit to Zepp

want to make additional edits?

you can still make adjustments at this point by using zeus dev again

My Troubleshooting Discoveries as FAQ

1)

Do I need to create and push a new ZAB file everytime I make edits?

Zepp OS Simmulator claims to support live changes. Ctrl + S in your code editor and the emmulator will refresh automatically. Sometimes the connection ends when it's been running for long periods of time and live edits stop tracking. Make sure to check in with Powershell when you feel your recent changes haven't been refected in the Zepp Sim.


2)

My sim connect status says logged and connected (zeus status) but connect sim failed (zeus dev)

Make sure the Zepp OS Simmulator app is open and running the whole time. Additionally, you can exit powershell and access the app at a latertime using zeus dev; however, deleting the app from the Sim and rebuilding may cause problems that prevent you from reconnecting your project to the Zepp Sim.


3)

In the simulator console log I get: reference error '__$$RQR$$__' is not defined at root/class context

This conflict is between imports and ui. The app crashes before the page can load. Make sure you are connsistent with the api version that the app is supportted by. Triple check your imports. Make sure your variables are declared/initialized.


4)

The app project shows up in the simmulator list but clicking it does nothing

A watch model will appear next to the project name, which is the same as what you selected to build/preview in powershell. If it says GTR4, for example, it expects you to download and open using that model only. You would also need to edit the page/index.js file of the corresponding model in the app folder and use correct API version in the code.


5)

My watchface briefly appears then goes dark

Check your localhost connection. If you run zeus build or zeus dev while the status is disconnected or closed, it wil not launch properly.


6)

How can I access all watch model options to chose from?

Some features aren't supported on all watch models, and the selected build API (i.e., v1, v2, v3, v4) affects this too. If you pick the 'empty' template upon creation, you will have all the availible watch options to select from.
